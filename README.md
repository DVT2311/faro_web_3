# FARO Cafe Website

Dựng từ thiết kế Figma `Faro-Web-dev`. Xem `CLAUDE.md` (nguyên tắc chung), `DESIGN.md` (chi tiết thiết kế), `PROGRESS.md` (tiến độ), `task_context.md` (tóm tắt quyết định).

## Chạy dự án
```
npm install
npm run dev
```
Mở địa chỉ mà `serve` in ra (mặc định `http://localhost:3000`).
